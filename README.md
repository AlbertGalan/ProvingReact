# ProvingReact / Coin-FlipTower download and GDD reader

This project was created initially to learn react and at the same time improve my presentation of Coin FlipTower by making the GDD more comfortable to read and the game itself easier to download.
--
To enter the website go into [Coin-FlipTower Download_and_GDD](https://albertgalan.github.io/ProvingReact/).

There you will find the cover of the game, if you click on it, the cover splits in two, on the leftside there's the GDD on three different languages and on the rightside, you will find a CD clicking on it
will start the download.

For more information about CoinFlipTower: [CoinFlipTowerRepo](https://github.com/AlbertGalan/CoinFlipTower)
